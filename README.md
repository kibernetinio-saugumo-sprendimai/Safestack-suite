# SafeStack Suite

Seven local-first security and privacy tools. Each project is an independent MVP with a read-only or explicit-action boundary.

| Project | Purpose |
|---|---|
| safestack-vault | Encrypted secrets store |
| safestack-dns-shield | Local DNS blocklist generator |
| safestack-home-soc | Home network inventory |
| safestack-backup-guardian | Backup integrity manifests |
| safestack-privacy-lens | Privacy posture checks |
| safestack-usb-sentinel | USB/file intake hashing |
| safestack-incident-kit | Evidence collection bundle |

See each directory README. Run `python -m unittest discover -v` for shared smoke tests.
